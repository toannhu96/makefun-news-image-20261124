A newspaper-style poster of one day's world news, rendered once by hand and delivered by a tiny Node 22 TypeScript program. It is an entry for make.fun's news-image bounty: the program writes a single 1024×1024 PNG to `/output/entry.png`, with no network access and no rendering at run time. Seven panels cover the day: Russian missiles over Poland and NATO's response, Ukrainian naval drones sinking a Russian warship off Libya, Iranian strikes on Gulf bases and new US sanctions, Nvidia reinstating Jensen Huang, Israeli strikes in Gaza, India's flood relief for Nepal, and COP31 closing without a climate pact.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
```
